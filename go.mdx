## Install

```bash
go get github.com/zerodrop-dev/zerodrop-go
```

Zero dependencies — stdlib only. Go 1.21+.

## Quick start

```go
package main

import (
	"context"
	"fmt"
	"time"

	zerodrop "github.com/zerodrop-dev/zerodrop-go"
)

func main() {
	client := zerodrop.New()
	inbox := client.GenerateInbox()
	// => "swift-x7k29a@zerodrop-sandbox.online"

	// Trigger your app's email flow with the inbox address...

	email, err := client.WaitForLatest(context.Background(), inbox, &zerodrop.Options{
		Timeout: 15 * time.Second,
	})
	if err != nil {
		panic(err)
	}

	fmt.Println(email.OTP)       // "123456" — auto-extracted, no regex
	fmt.Println(email.MagicLink) // "https://..." — auto-extracted
}
```

## go test

```go
func TestSignupEmailVerification(t *testing.T) {
	client := zerodrop.New()
	inbox := client.GenerateInbox()

	// Trigger signup with the inbox address...

	email, err := client.WaitForLatest(context.Background(), inbox, &zerodrop.Options{
		Timeout: 15 * time.Second,
	})
	if err != nil {
		t.Fatalf("no verification email: %v", err)
	}

	if email.OTP == "" {
		t.Fatal("expected OTP in verification email")
	}
}
```

## SSE and polling

`WaitForLatest` uses Server-Sent Events by default with automatic polling fallback:

```go
// Force polling mode if needed
email, err := client.WaitForLatest(ctx, inbox, &zerodrop.Options{
	DisableSSE: true,
})
```

## Filtering

```go
email, err := client.WaitForLatest(ctx, inbox, &zerodrop.Options{
	Timeout: 15 * time.Second,
	Filter: &zerodrop.Filter{
		From:    "noreply@yourapp.com",
		Subject: "Verify",
		HasOTP:  zerodrop.Bool(true),
	},
})
```

All string filters are case-insensitive partial matches.

## Parallel tests

`GenerateInbox` runs locally — safe with `t.Parallel()`, zero collisions:

```go
func TestParallelSignups(t *testing.T) {
	t.Parallel()
	client := zerodrop.New()
	inbox := client.GenerateInbox() // unique per call
	// ...
}
```

## Free API key (private inboxes)

Without a key, anyone who knows an inbox's name can read it, and one sender can reach only 5 different inboxes a day: past that, the inbox gets a notice from `notice@zerodrop.dev` instead of the email. Sign in with GitHub at [zerodrop.dev/keys](https://zerodrop.dev/keys) for a free key and set it as `ZERODROP_API_KEY`. With zerodrop-go v0.2.0 or later, `zerodrop.New()` reads it, `GenerateInbox` starts names with your key's prefix, only your key can read those inboxes, and mail to them isn't limited:

```go
client := zerodrop.New() // reads ZERODROP_API_KEY
inbox := client.GenerateInbox()
// => "k7x2-swift-x7k29a@zerodrop-sandbox.online", where k7x2 is your prefix
prefix := client.Prefix() // "k7x2"
```

## Error handling

```go
var timeoutErr *zerodrop.TimeoutError
if errors.As(err, &timeoutErr) {
	// No email arrived
}
if errors.Is(err, zerodrop.ErrUnauthorized) {
	// The inbox belongs to another key's prefix, or your key is wrong;
	// err.Error() carries the server's reason
}
if errors.Is(err, zerodrop.ErrHeld) {
	// No API key, and ZeroDrop held the email (daily limit);
	// err.Error() is the server's reason
}
if errors.Is(err, zerodrop.ErrInvalidAPIKey) {
	// The key has a line break or similar in it; copy it again
}
```

Since v0.2.0 the 401 error wraps `ErrUnauthorized` with the server's reason, so compare with `errors.Is`, not `==`.

`ErrHeld` is new in v0.3.0. Without an API key, one sender can reach only 5 different inboxes a day; past that, the email isn't stored and the inbox gets a notice instead. `WaitForLatest` then returns an error matching `ErrHeld` at once rather than waiting for the timeout, and `FetchLatest` returns it when nothing matches. Older versions treat the notice as an email: without a filter they return it, and a filter such as `HasOTP` skips it, so the wait times out. A free key from [zerodrop.dev/keys](https://zerodrop.dev/keys) lifts the limit for inboxes under your key's prefix.

## Workspaces & self-hosting

```go
client := zerodrop.New(
	zerodrop.WithAPIKey(os.Getenv("ZERODROP_API_KEY")), // optional since v0.2.0: New reads it anyway
	zerodrop.WithBaseURL("https://your-instance.yourdomain.com"),
)
```
